# Avery Quinn — Creative Technologist

A polished, responsive portfolio concept built around a fictional creative technologist. All persona details and case studies are speculative design content, not claims about a real individual or real client engagements.

## Stack

- React + Vite
- Framer Motion for expressive UI transitions and reveals
- GSAP + ScrollTrigger for scroll progress, parallax, and motion choreography
- Lucide React for interface iconography
- Responsive CSS with reduced-motion support

## Experience map

- **Hero:** layered portrait composition, interactive tilt, orbital details, and scroll-linked movement
- **Point of view:** editorial biography and design principles for the fictional persona
- **Expertise:** product thinking, experience design, and creative development
- **Selected concepts:** three speculative case studies with interactive detail dialogs
- **Approach:** a four-part process section with scroll-triggered rule reveals
- **Contact:** a sample contact action using a placeholder email address

## Local development

    npm install
    npm run dev

Production build:

    npm run build
    npm run preview

## Publishing notes

- The persona, narrative, and case studies are fictional.
- Project photography is loaded from the supplied ImgBB direct-image URLs.
- The contact address is a placeholder (hello@example.com) and should be replaced only if this demo is adapted for a real portfolio.
- Verify image hosting permissions and asset availability before production use.

Deploy through Vercel or Netlify with npm run build and dist as the output directory.
