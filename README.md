# Shivatm Prakash — Digital Portfolio

A responsive, editorial-style portfolio built with React + Vite, Framer Motion and GSAP/ScrollTrigger. The design takes cues from the supplied Figma portfolio: clear section labels, restrained typography, subtle borders, project cards and a focused contact section.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Stack
- React + Vite
- Framer Motion for reveal transitions
- GSAP + ScrollTrigger for hero and scroll details
- Lucide React icons
- Responsive CSS with reduced-motion support

## Sections
- Hero / introduction
- Journey
- Experience and direction
- Skill set
- Toolbox
- Selected work
- Contact and social links

## Before publishing
- Replace the sample project descriptions and stock images with your real work.
- Update the email address and social profile URLs in `src/App.jsx`.
- Check all image licenses and availability before production use.

## Deploy
Import this repository into Vercel or Netlify. Use `npm run build` as the build command and `dist` as the output directory.
